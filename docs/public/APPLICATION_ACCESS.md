# 应用端口与账号密码

服务总览默认仅显示已纳管项目，“清除筛选”也恢复到已纳管范围。需要查找其他项目时，可在状态筛选中切换“全部项目”或“未纳管”。从其他页面明确跳转到一个未纳管项目时，会临时显示全部项目以定位目标。

服务总览中，一个 Compose 包含多个应用时，卡片按应用 / 服务名称分别展示全部候选 Web 入口，不再合并进单个下拉按钮。展开后，每个容器分别列出 `宿主端口 → 容器端口/协议`，IPv4 与 IPv6 的重复映射合并。TCP 和 UDP 保持区分，数据库等数据端口保留映射信息，但不生成浏览器入口。链接是根据已发布端口推断的候选入口，不代表已经完成 HTTP 连通性验证。

容器目标端口为 443 时使用 HTTPS。无发布端口时显示“未发布宿主端口”。主机网络读取镜像的 EXPOSE 声明，分别展示端口和候选入口，并标明“主机网络（声明）”；没有声明时显示“主机网络 · 无端口映射”。声明不代表进程已实际监听，最终端口以应用配置为准。

点击卡片右侧钥匙图标直接进入“账号密码”页签；展开区的“环境与密钥”默认进入“环境变量”。两处打开同一个窗口，均可在页签间切换。环境变量沿用原有文件编辑与保存/应用流程；账号密码页签可新增、修改、删除最多 50 组账号密码。每组可填写应用 / 服务、账号、密码或密钥；密码默认隐藏。账号密码默认采用紧凑“键值对”视图，每组一行，应用、账号和密码可单独复制；可切换回“表单”，切换不丢失输入并重新隐藏密码。复制保留原始值，HTTP 入口使用兼容复制方式，复制反馈不包含凭据内容。账号密码页签仅记录登录信息，不会修改应用内部的密码，也不会重启容器。两类数据分别保存，切换页签前会检查未保存内容；未启用 Compose 目录能力的项目仍可维护账号密码，环境变量页签不可用。

凭据按 Docker 节点和项目隔离，只在打开维护弹窗时通过已鉴权的专用接口读取，响应禁止缓存，不进入项目列表或自动提供给 AI 的上下文。切换节点、离开服务页或关闭窗口后清理弹窗状态。保存使用版本检查；发现其他页面已保存时拒绝覆盖并保留当前输入，需重新打开后核对。

凭据保存在面板 SQLite 数据库中，沿用现有数据库加密配置。未启用数据库加密时为明文；界面的密码掩码不代表静态加密。数据库和备份需要妥善保管，启用静态加密的方法见 [数据库加密](DATABASE_ENCRYPTION.md)。操作记录只记录维护的组数，不记录账号密码。设置导出不包含此独立数据表；完整数据库备份包含凭据。
