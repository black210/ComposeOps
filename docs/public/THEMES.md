# 界面主题

顶部的太阳/月亮图标、登录页右上角和“设置 → 偏好 → 界面主题”均可选择：

- **浅色**：白色面板、冷灰背景、深色文字；首次打开默认使用。
- **深色**：保留现有暗色工作台。
- **跟随系统**：随操作系统的浅色/深色设置自动变化。

切换即时生效，无需保存或重新登录。选择保存在当前浏览器的 `composeops:theme` 中，同源标签页保持同步；其他设备独立选择。浏览器禁止本地存储时，本次切换仍可使用，但刷新后可能不能保留。

主题覆盖登录、导航、项目、表格、表单、弹窗、AI 工作台与富内容、拓扑和图表。Monaco 配置编辑器和两处 xterm 终端会跟随切换；切换不会重新建立终端连接，也不会保存或修改应用配置。图表 PNG 导出会冻结当前主题颜色。

## 实现与验证

- `frontend/public/theme-init.js` 在 Vue 和样式加载前恢复主题，使用外部脚本兼容默认 CSP；不依赖内联脚本。
- `frontend/src/lib/theme.js` 管理偏好、系统主题监听与跨标签同步。
- `frontend/src/theme.css` 定义浅色颜色、状态文字与组件外观；现有暗色样式中的固定颜色改为共享语义变量。
- 前端测试覆盖默认值、持久化、系统变化、跨标签、存储受限、首屏一致性，以及终端切色不重连。

本次仅修改前端显示和浏览器偏好，不改变后端接口、备份能力或服务器项目的控制权限。
